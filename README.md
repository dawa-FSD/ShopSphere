# 🛍️ ShopSphere

ShopSphere is a modern React e-commerce web application where users can browse products, search and filter products, view product details, add products to a cart, checkout, and view their order history.

## 🚀 Features

- 🏠 Home page
- 🛍️ Products page
- 🔎 Product search
- 📂 Category filtering
- 💰 Price sorting
- 📄 Product details
- 🛒 Shopping cart
- ➕ Increase product quantity
- ➖ Decrease product quantity
- ❌ Remove products from cart
- 💾 Cart data stored in LocalStorage
- 💳 Checkout
- 📱 TeleBirr payment option
- 💵 Cash on Delivery option
- 📦 Order history
- 🔗 React Router navigation
- ❌ 404 Not Found page
- 📱 Responsive design

## 🛠️ Technologies Used

- React
- JavaScript
- JSX
- React Router DOM
- Context API
